# 松鼠看板 UI 与改进记录

## 视觉方向

圆脸、大尾巴、抱松果的卡通松鼠是品牌记忆点。默认浅色主题，清爽的蓝色主按钮搭配白色卡片。借鉴板栗看板的全局导航 / 当前看板操作分层、随内容增长的列表以及明显的添加卡片入口，重新设计为适合中文轻量协作的工作空间。

| Token | 色值 | 用途 |
| --- | --- | --- |
| 清爽蓝 | `#2563EB` | 主按钮、品牌 |
| 浅灰蓝 | `#F7F9FC` | 工作区背景 |
| 纸白 | `#FFFFFF` | 导航、列表、卡片 |
| 深灰蓝 | `#263449` | 中文正文 |
| 蓝灰 | `#68788E` | 次要说明 |
| 浅蓝色 | `#EDF4FF` | 选中导航、悬停背景 |

中文与西文统一使用随应用部署的 Noto Sans SC 可变字体（400–700），WOFF2 按 Unicode 分段按需加载，运行时不依赖外部字体服务。字体采用 OFL 许可，许可证见 `web/public/fonts/OFL.txt`；系统字体只作为加载期间和缺字时的回退。标题 25px，任务内容 13px，辅助说明 11–12px。主要内容左对齐，列表约 292px，卡片 8px 圆角，列表 12px 圆角。交互反馈使用短动画，遵循 reduced-motion。

```text

│ 松鼠看板      │ 工作空间 / 当前看板       筛选 账户 │

│  看板 B      │ ┌待办────┐ ┌进行中──┐ ┌已完成──┐ │
│              │ │ 卡片   │ │ 卡片   │ │ 卡片   │ │
│ 归档箱        │ │ +添加  │ │ +添加  │ │ +添加  │ │
│ 分享 / 指南   │ └────────┘ └────────┘ └────────┘ │
└──────────────┴───────────────────────────────────┘
```

移动端折叠侧栏，保持横向看板滚动。深色模式使用对应语义变量。品牌 logo 使用透明 PNG（256px），favicon 为 64px；其余图标不引入图标库。蓝色按钮使用白色文字保证可读性，卡通松鼠保留暖橙色，与界面形成自然的冷暖搭配。

## 本次修正

- 品牌名称、登录页、浏览器标题、favicon、主界面和服务日志统一为松鼠看板。
- 快捷键 N 打开建卡输入，而非立即创建空卡片；弹层和编辑期间禁用全局建卡。
- 常用中文输入位置避免输入法 Enter 误提交。
- 建卡 / 建列保留失败草稿并防止重复提交；API 写入错误统一可见。
- 标题编辑按钮独立于打开详情，避免双击先打开抽屉的冲突。
- 弹层焦点循环、Esc 和焦点恢复；归档箱彻底删除需确认。
- 卡片详情可选择目标列表；切换卡片清理旧详情和清单草稿。
- 切换看板防止慢请求覆盖新看板，并记住上次打开的看板。
- 拖拽保存后合并服务端排序位置；同步事件先校验所属看板。
- 读取清单项限定在当前卡片，避免每次扫描全库清单数据。
- 附件要求有效会话、下载使用 attachment 与 nosniff，限制文件和请求大小；删除卡片、列表、看板时清理附件实体，避免磁盘残留。
- 修正 Docker 构建路径；生产数据改命名卷，保留非 root 运行。
- dev 端口与 Vite 代理自动同步，启动失败退出，停止时只清理自身子进程。
- 保留 Playwright 历史记录，避免加入日常开发与生产镜像。

## 验证与后续边界

已通过 TypeScript / 前端构建、Go 核心测试和实际 API 链路检查。已在 Chrome 对照板栗看板，并验证分享管理的状态筛选、菜单退出与焦点恢复、分享设置及卡片描述的草稿关闭保护；已验证列表鼠标排序与颜色持久化，复杂长看板卡片拖拽仍待真实任务验证；本机 Docker 服务未运行，已检查 Compose 配置；镜像实构建需启动 Docker 后执行。

后续优先级建议：先用真实任务验证长看板拖拽手感、移动端手势与多人编辑冲突；再按实际需求增加批量操作、导入导出和更细的权限。管理员拥有完整工作空间，免登录访客限制在单个分享看板内，SQLite 定位单实例。完整离线编辑、冲突合并与历史撤销暂未实现。

## 单管理员与访客分享

移除成员管理与账号创建入口，管理员保留修改密码功能。每条分享有独立名称、固定短链接、六个权限开关和有效期，同一看板可建立多条记录；内容实时更新。访客使用独立界面，保留品牌、筛选、卡片详情、清单、评论和授权后的附件下载；不会显示其他看板导航与管理入口。移动卡片用列表选择器及上下移按钮，适合键盘和触屏。访客前台每 15 秒刷新，权限撤销由后端立即校验。评论昵称明确标记为访客。

## 图标与分享管理细节

页面图标统一为本地 SVG，统一尺寸、线宽、对齐和按钮名称；不再用依赖系统字体的字符图标。左侧增加独立「分享管理」页面 `/shares`，列表显示分享状态、权限摘要、有效期与访客会话，支持搜索、筛选、新建、编辑、复制、停用和删除独立记录。空列表和请求失败有对应提示。

菜单通过 portal 绘制，避免被列表和抽屉裁切；支持方向键、Home / End、Esc 与焦点恢复。弹层限制在视口内并允许滚动。分享设置采用明确的权限开关，修改后先保存再复制；离开前提示放弃草稿。卡片写入串行处理，失败保留输入，清单、附件及卡片删除均需确认。未知 API 路径返回 JSON 错误，前端校验响应格式，避免旧服务返回 HTML 导致页面空白。

## 固定记录与卡片闭环

移除重新生成操作，使用 22 个字符的随机短码；原长链接、历史访客会话继续有效。迁移前备份数据库，移除看板分享的唯一约束。记录的名称、权限、有效期可编辑，所属看板与地址固定。管理页支持直接进入、刷新及前进 / 后退。

看板导航使用带表情的小橡果 SVG，呼应卡通松鼠。卡片使用底部层叠阴影，悬停轻微上浮，拖动时透视倾斜并加深悬浮阴影，编辑按钮不再显示明显的方框。卡面显示描述摘要、附件数、评论数、日期与清单进度；详情、摘要、看板读取使用一致的计数。修正详情附件计数缺失；新建标签自动添加到当前卡片，失败保留标签与草稿供重试。日期改为先编辑再保存，避免分段编辑导致日期回弹；清单连续添加后恢复输入焦点。

## 输入与布局细节

输入框、文本域和选择框的焦点仅改变边框，不使用光晕或阴影。按钮文字不换行、不收缩；清单输入与操作按钮保持同高，窄屏下仍可完整操作。

卡片封面绘制在边框内，列表滚动容器不裁切第一张卡片的圆角。抽屉和对话框通过 portal 绘制，页眉不会遮住关闭按钮或列表选择器；内容区域独立滚动。标题与评论组件不使用可能与相邻未编号元素冲突的数字 key，连续保存不会重复渲染输入框；长标题随输入和视口宽度自动调整高度。

点击列表圆点或菜单「设置列表颜色」可选择预设或自定义配色。颜色保存到列表记录并随排序移动，管理员与共享看板显示一致。历史数据库迁移前创建 `pre-column-colors` 一致性备份，保留原配色和业务内容。橡果图标按看板 ID 使用黄金角分配色相，避免三色循环且不受新增、删除或排序影响。

窄屏标题与看板操作分行排列，关闭的侧边导航不会获得焦点；快捷说明和次要工具不占据移动端操作区。

## 附件预览与快捷定位

「添加清单」明确为「添加子任务清单」，空状态解释它用于拆分小步骤和显示进度。附件行包含缩略图、完整名称提示、大小、预览、下载和删除；原有附件无需迁移。复用同一轻量预览组件供管理员与获授权访客使用，Office 文档可通过私有部署的 Gotenberg / LibreOffice 转 PDF，原文件及缓存均复用附件授权。

卡面附件和评论数量改为独立按钮，阻止拖拽事件冒泡。悬停 / 键盘聚焦按需读取内容，通过 portal 在图标附近显示列表；180 ms 离开延迟允许移入浮层，保持在屏幕范围内。图片有缩略图，点击附件可直接打开预览；评论展示最近三条。点击图标进入对应区域，评论区保留足够滚动空间，避免短内容和异步加载把定位卡在底部。发表评论 / 删除评论后刷新本地卡片计数。

配色参考 [Trello 多色列表选择](https://support.atlassian.com/trello/docs/change-the-color-of-a-list/) 的预设与选中反馈，采用 12 个明快色系。封面 / 标签增加原生颜色输入，与列表自定义选择保持一致。浅亮颜色标签使用深色文字，兼顾辨识度。

独立测试数据已验证：鼠标附件浮层与直接图片预览、PDF 原生查看器、中文文本及普通文件回退、PDF 上传后的数量更新、自定义封面和标签保存、12 色列表选择、免登录只读访客预览、390px 抽屉与图片预览无横向溢出。Go 回归覆盖预览鉴权、文件类型、分段读取、分享范围与权限关闭；前端构建和 Go vet 通过。


## 看板外观与动效

- 工具栏「外观」按看板保存背景：8 组浅色、自定义原生颜色选择、4 张本地 SVG 风景（森林、海边、远山、星球）及上传图片。上传支持 PNG / JPG / WebP / GIF / AVIF，最大 12 MB，存放数据目录 `backgrounds/`，Compose 的数据卷已覆盖。选择后自动保存；恢复默认会清理旧上传图片。共享访客只能经有效分享访问该看板当前背景。
- 缩放范围 25%–150%，右下角浮层提供滑块、加减、重置、适应宽度、移动画布及缩略图。画布空白处滚轮缩放，列表内部滚动；Ctrl / ⌘ + 滚轮及触控板捏合可在列表上缩放。按看板在浏览器记忆缩放；弹层不受缩放影响。
- 对话框、抽屉、菜单和悬浮预览保留 180 ms 退出时间，避免立即卸载吞掉动画。明暗切换以按钮为中心圆形扩散；不支持 View Transition 的浏览器直接切换。尊重系统减少动态效果设置。
- 卡片列表归属使用统一下拉组件；封面色板收进菜单；清单名称支持编辑、保存和取消，保留全部子项与勾选状态；取消和失败保留原内容。

## 画布工具与大列表

移除右侧标题上方重复的「我的看板」，看板视图栏延伸到整个内容宽度。工作空间下拉的色块与左侧看板橡果图标使用同一 ID 配色。画布工具不随缩放变形，缩略图按需挂载并支持进出动画、点击与方向键定位，移动模式阻止卡片误触与拖拽冲突。

超过 80 张卡片启用动态高度虚拟列表，保留拖动中的节点。修复卡片键盘事件覆盖拖拽传感器的问题；空格启动 / 结束拖动，方向键移动，Enter 打开详情。搜索采用延迟渲染并回到列表顶部；跨列定位通过卡片到列表的映射完成。整列归档在一个事务内写入卡片状态与历史，避免逐张发起请求。

## 状态图标变形 / Morphing state icons

使用 `morphicons/react`，由 `web/src/MorphingIcon.tsx` 统一设置 1.7px 线宽、
currentColor、固定尺寸和 `reducedMotion="user"`。仅状态变更触发动画，首次渲染不播放，
卡片和列表中的批量静态图标继续使用原有 Icon。

可检查的位置：

1. 登录页、管理员页和分享页的主题切换：太阳 / 月亮。
2. 登录密码、添加成员、重置密码和修改密码：显示 / 隐藏眼睛。
3. 侧栏分割线按钮：展开 / 折叠。
4. 管理员与分享画布右下角：进入 / 退出全屏。
5. 管理员与分享画布右下角：缩略图 / 关闭。
6. 通用 Select 下拉框（角色、成员归属、卡片所属列表等）：向下 / 向上箭头。

测试：`tests/browser/morph-icons.cjs` 随可选浏览器回归运行，检查路径中间帧、
尺寸稳定、系统减少动态效果、密码值保留与连续切换。生产包 gzip 增量约 8.6 KB。

## 浮层进出动画

普通弹窗、菜单、卡片预览与缩略图共用 180ms 的透明度 / 位移过渡，
通过 `@starting-style` 定义首次进入状态，快速重开时从当前帧继续过渡。
管理员卡片抽屉与分享抽屉使用同样的向右位移，不在关闭时缩放。
`usePresence` 保留关闭节点 200ms（含一帧余量），关闭期间禁用交互，
弹窗标题、正文和底部操作区保留到卸载，避免内容高度跳变。
系统启用“减少动态效果”时过渡缩短至 1ms；不引入额外动画依赖、
逐帧 React 更新或常驻 `will-change` 图层。

`tests/browser/layer-motion.cjs` 随浏览器回归检查真实退出中间帧、
抽屉方向、弹窗高度与底部操作区保留；覆盖中英文、明暗主题和不同角色。

## 控件尺寸与字体层级

表单控件的 `font: inherit` 重置必须放在 `@layer base`，让 Tailwind 的组件字号、
字重和行高生效；不要在无层级的全局选择器中重新覆盖这些属性。
普通按钮和菜单使用 13px，小按钮使用 12px；菜单图标统一 15px、间距 8px、
最小行高 32px，长文字仍可按内容增高。看板操作栏按钮高 32px，
正文和页面标题保留独立字号，避免整体缩小页面。
`tests/browser/control-sizing.cjs` 验证实际计算样式，包括菜单图标、
筛选框及 placeholder、工具栏和抽屉按钮；随角色、语言、主题回归运行。

## 列表滚动稳定性

卡片滚动区使用 `scrollbar-gutter: stable` 预留滚动条位置，滑块仍仅在悬停时显示。
禁止根据当前 `offsetWidth - clientWidth` 动态回写同一滚动区的 padding 或 margin：
文字换行会改变内容高度，在临界溢出和非整数缩放下形成布局反馈循环。
滚动观察器仅更新顶部、底部按钮的可用状态，不修改滚动区尺寸。
`tests/browser/scroll-stability.cjs` 在隔离浏览器内检查溢出前后的内容宽度、
120 张卡片和 100% / 105% / 110% / 125% 缩放下的连续帧稳定性，
覆盖管理员、协作分享与只读分享；仅修改测试页面 DOM，不写入看板数据。
