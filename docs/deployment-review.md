# 开源发布回归记录 / Release review — 2026-10-15

## 已修复 / Implemented

- MIT LICENSE，中英文 README、贡献与安全说明、依赖许可清单；许可证随运行镜像分发。
- 服务端强制首次改密；修改密码时原子撤销其他会话；有界内存登录限流及 Retry-After。
- 子管理员/成员可排序其有权限的看板，仍禁止跨空间访问。
- 分享编辑关闭、Esc 和取消编辑均保护未保存草稿。
- 卡片非法 JSON 不再创建数据；标题、描述、日期、封面统一校验；中文/英文/emoji 同按 Unicode 字符计数。
- 看板描述可清空，更新采用单次 SQL 原子写入。
- Vite 7 / Tailwind 4 与密码库升级；统一格式化，拆出共享菜单组件；保持无额外生产服务依赖。
- `KANBAN_VOLUME` 可配置，备份恢复采用全新空卷并保留回滚路径；监听地址说明与 Compose 一致。
- Docker 基础镜像固定 manifest digest；CI 包含真实跨系统 dev 启动、可选浏览器回归、Office 转换和 SBOM/镜像元数据产物。
