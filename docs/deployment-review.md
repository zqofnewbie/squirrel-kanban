# Docker 与开源发布检查（2026-10-11）

## 已整改

- 多阶段构建，前端锁文件安装、Go 模块校验和只读模块构建；运行镜像不包含 Node 或编译器。
- Go 构建镜像更新为 1.27.2，Alpine 运行镜像更新为 3.24.2。
- 固定非 root UID/GID 10001；只读根文件系统、移除 capabilities、禁止提权；数据卷可写，临时目录有大小限制，日志轮转。
- 保留现有数据卷名称，删除固定 container_name；多实例需自行指定不同数据卷和端口。
- Compose 缺少密码拒绝解析；后端首次生产初始化拒绝默认/空白/过短密码。已有数据库不会被环境变量重置。
- 数据库健康检查 `/healthz`；HTTPS Secure Cookie 可配置。
- 构建上下文排除环境变量文件、数据库、私钥、包仓库凭据、本地工具目录和测试产物。
- 新增 CI、贡献说明、安全报告说明；本地测试产物随 dev 重置归入忽略的 `backups/`，不会进入发布提交。

## 已执行验证

两套 Compose 配置校验、缺少密码失败测试、前端测试与构建、完整 Go 测试和 go vet 均通过。npm 官方生产依赖审计报告 0 条漏洞；govulncheck 未发现当前调用路径可达漏洞，但依赖模块含 22 条未调用到的漏洞记录。

## 尚未完成，不能视为已发布就绪

1. 当前 Docker 客户端使用的 OrbStack socket 不存在，无法执行真实镜像构建和容器启动。CI 已配置基本冒烟测试，但本地尚未实跑；Office 可选预览容器也需要真实文件验证。
2. npm 全量审计报告 9 条开发依赖漏洞（6 high、3 moderate），涉及 Tailwind 3 依赖链及 Vite/esbuild。建议单独升级与回归构建工具，不执行盲目的 `audit fix --force`。
3. LICENSE 需所有者确定；字体已有 OFL 声明，其他资产和依赖许可仍需完成发布清单。
4. 公开前扫描完整 Git 历史。当前删除/忽略文件不能移除历史中的内容；若发现真实凭据，先撤销或轮换，再清理历史。
5. 正式发行需记录镜像 digest、版本和提交，按发布流程生成 SBOM 与扫描报告；当前没有签名发布镜像。

基础镜像标签不等同于内容锁定，更新后需要重新测试。本报告是当前范围内的工程检查，不是完整渗透测试。
